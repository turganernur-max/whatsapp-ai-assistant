# WhatsApp AI Assistant

AI-помощник для WhatsApp Business: принимает сообщения клиентов через официальный **WhatsApp Cloud API**, отвечает на казахском и русском с помощью **Claude** по вашим инструкциям и базе знаний, работает круглосуточно на облачном сервере. Управляется из мобильной панели на iPhone.

👉 **Пошаговое подключение для не-программиста: [docs/SETUP_RU.md](docs/SETUP_RU.md)**

## Возможности

- Приём и отправка сообщений через WhatsApp Cloud API, проверка подписи webhook (`X-Hub-Signature-256`).
- Ответы Claude (по умолчанию `claude-opus-5-5`, можно выбрать Sonnet/Haiku в панели), строго по инструкциям и базе знаний: факты берутся только из базы, иначе вопрос передаётся владельцу.
- Казахский и русский: AI отвечает на языке клиента.
- Контекст переписки (последние N сообщений), несколько сообщений подряд склеиваются в один ответ.
- Голосовые → текст (Whisper через Groq/OpenAI, необязательно). Фото понимает Claude.
- Сообщение «вам отвечает AI-помощник» в начале переписки с новым клиентом.
- Передача владельцу: жалобы, возвраты, неизвестные вопросы → метка «Нужен владелец» + push-уведомление (ntfy).
- Вмешательство владельца: ответ из панели или из приложения WhatsApp Business (coexistence, `smb_message_echoes`) ставит AI на паузу в этом диалоге.
- AI вкл/выкл глобально и для отдельных контактов, стоп-слова для клиента.
- Ограничение месячных расходов, учёт стоимости каждого ответа, кеширование промпта для экономии.
- Защита: дедупликация сообщений (повторы webhook от Meta), защита от зацикливания с другими ботами, соблюдение окна 24 часа, равномерная отправка, восстановление незавершённой работы после перезапуска, автоудаление старых данных.
- Продажи: каталог товаров и услуг (цена, фото, наличие), режим продавца (потребность → предложение → возражения → оформление), заказы с уведомлением владельцу, оплата через Kaspi (AI даёт реквизиты, «я оплатил» → проверка владельцем; AI сам оплату не подтверждает).
- Фото, видео и файлы: медиатека, которую AI отправляет по ситуации; видео с iPhone автоматически конвертируются в MP4 до 16 МБ.
- Живой стиль общения: коротко, без шаблонных фраз, ответ 2–3 сообщениями с паузой «печатает…». AI сам не называет себя ботом, но честно отвечает, если клиент прямо спросит.
- Напоминания клиенту, который замолчал: 1 раз или «настойчиво» до ответа — только в бесплатные 24 часа; рассылки по одобренным шаблонам Meta с оценкой стоимости и расписанием.
- Предупреждение в панели и push, если токен WhatsApp истёк; на Render free сервер не засыпает (self-ping).
- Панель (PWA): Диалоги, Заказы, Инструкции + тест AI, Знания (база, каталог, медиатека), Отчёты (статистика, расходы, лимит), Настройки (AI, рассылки и напоминания, подключение WhatsApp, данные), переключатель AI.

## Устройство

```
src/
  index.ts       запуск, корректное завершение, восстановление после сбоя
  server.ts      Fastify: /webhook, /health, API панели, раздача public/
  processor.ts   очередь: дедупликация, склейка, правила, вызов AI, отправка, передача владельцу
  ai.ts          промпт и вызов Claude (структурированный JSON-ответ, кеш, fallback при отказе)
  whatsapp.ts    WhatsApp Cloud API: отправка, медиа, подпись, разбор webhook
  db.ts          Postgres (DATABASE_URL) или встроенный PGlite, миграции
  settings.ts    настройки, редактируемые из панели
  auth.ts        вход в панель (пароль, подписанная cookie, защита от подбора)
  sales.ts       каталог, заказы, оплата
  campaigns.ts   напоминания и рассылки
  media.ts video.ts  медиатека, конвертация видео (ffmpeg)
  stt.ts notify.ts pricing.ts store.ts config.ts
public/          мобильная панель (без сборки, CSP без inline-скриптов)
test/            юнит- и сквозные тесты (фейковый Graph API и Claude)
```

Все секреты — только в переменных окружения (см. `.env.example`). В репозитории их нет.

## Разработка

```bash
npm install
npm test                 # 44 теста; TEST_DATABASE_URL=postgres://... — прогон на Postgres
npm run build && npm start
```

Развёртывание: `render.yaml` (Render Blueprint) или `Dockerfile` для любого VPS.
