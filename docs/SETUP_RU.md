# Пошаговое подключение (только с iPhone)

Инструкция рассчитана на человека без опыта программирования. Всё делается в Safari на iPhone.
Если сайт выглядит неудобно или нужной кнопки не видно, нажмите **«аА»** в адресной строке → **«Запросить настольный веб-сайт»**.

> ⚠️ **Правила безопасности**
> - Ключи и пароли вставляйте **только** в настройки сервера Render (раздел *Environment*). Никогда не пишите их в GitHub, в чаты и не отправляйте мне.
> - Ничего платного не подключайте, пока не решите сами. Ниже везде указано, где бесплатно, а где платно.
> - Пока вы не включите переключатель **AI** в панели, программа никому ничего не отвечает.

---

## Что получится в итоге

```
Клиент пишет в WhatsApp ──► Meta (WhatsApp Cloud API) ──► ваш сервер на Render ──► Claude (AI)
                                                              │
                                     ответ клиенту ◄──────────┘
                     вы управляете всем через панель на iPhone (https://ваш-сервер.onrender.com)
```

| Сервис | Для чего | Стоимость |
|---|---|---|
| **Meta for Developers** (WhatsApp Cloud API) | приём и отправка сообщений | Ответы клиенту в течение 24 часов после его сообщения — бесплатно. Тестовый номер — бесплатно |
| **Claude API** (Anthropic) | искусственный интеллект | Платно, по факту использования (~$0.01–0.02 за ответ на модели Opus 5.5). Нужно пополнить баланс минимум на $5 — **только с вашего решения** |
| **Render** | сервер, работает 24/7 | Бесплатный тариф (засыпает без нагрузки — решается шагом 7). Платный Starter $7/мес надёжнее — по вашему желанию |
| **Neon** | база данных (диалоги, настройки) | Бесплатно |
| **Groq** (необязательно) | расшифровка голосовых | Бесплатный лимит |
| **ntfy** (необязательно) | push-уведомления на iPhone | Бесплатно |

Порядок: **1 → 2 → 3 → 4 → 5 → 6**. Шаги 7–9 — по желанию.

## Шаг 1. Ключ Claude API

1. Откройте **https://platform.claude.com** → зарегистрируйтесь (можно через Google).
2. **Settings → Billing** — здесь пополняется баланс (минимум $5). ⚠️ Это платный шаг: делайте его, только если решили. Без баланса AI отвечать не будет, но всё остальное подключить можно.
3. **Settings → Limits** — поставьте месячный лимит расходов, например **$10**. Это вторая защита в дополнение к лимиту в самой программе.
4. **Settings → API Keys → Create Key** → назовите `whatsapp` → **скопируйте ключ** (начинается с `sk-ant-…`). Он показывается один раз — сохраните его в «Заметках» (лучше в заметке с паролем).

## Шаг 2. База данных Neon (бесплатно)

1. Откройте **https://neon.com** → **Sign up** → войдите через **GitHub** или Google.
2. Создайте проект: имя `whatsapp-ai`, регион **AWS Europe Central (Frankfurt)**.
3. На странице проекта нажмите **Connect** → скопируйте строку подключения. Она выглядит так:
   `postgresql://...@...neon.tech/neondb?sslmode=require`
   Сохраните её в заметке — это `DATABASE_URL`.

## Шаг 3. Сервер Render

1. Откройте **https://render.com** → **Get Started** → войдите через **GitHub**.
2. Разрешите Render доступ к репозиторию **whatsapp-ai-assistant**.
3. Нажмите **New + → Blueprint** → выберите репозиторий `whatsapp-ai-assistant`.
   Ветка (Branch): **`main`**.
4. Render прочитает файл `render.yaml` и попросит заполнить значения:

   | Поле | Что вписать |
   |---|---|
   | `ADMIN_PASSWORD` | придумайте пароль для панели, **не короче 10 символов** |
   | `DATABASE_URL` | строка из шага 2 |
   | `ANTHROPIC_API_KEY` | ключ из шага 1 |
   | `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_BUSINESS_ACCOUNT_ID`, `META_APP_SECRET` | пока оставьте пустыми, заполним в шаге 4 |
   | `STT_API_KEY`, `NTFY_TOPIC` | пусто (необязательные, шаги 8–9) |

   `SESSION_SECRET` и `WEBHOOK_VERIFY_TOKEN` Render создаст сам. Адрес сервера и порт программа узнаёт от Render автоматически.
5. Нажмите **Apply / Deploy**. Подождите 3–5 минут, пока статус станет **Live**.
6. Вверху страницы сервиса будет адрес вида `https://whatsapp-ai-assistant-xxxx.onrender.com`.
   - Откройте `адрес/health` — должно быть `{"ok":true,...}`.
   - Откройте сам адрес → войдите с паролем `ADMIN_PASSWORD`. Это ваша **панель управления**.
   - Safari → **Поделиться → На экран «Домой»** — панель будет открываться как приложение.

## Шаг 4. Meta: приложение WhatsApp (бесплатно)

1. Откройте **https://developers.facebook.com** → войдите через Facebook → **Get Started** (регистрация разработчика, подтверждение телефона).
2. **My Apps → Create App**.
   - Use case: **Connect with customers through WhatsApp** (Связаться с клиентами через WhatsApp).
   - Выберите или создайте **бизнес-портфолио** (Business portfolio).
3. В меню приложения: **WhatsApp → API Setup** (Настройка API). Здесь:
   - **Temporary access token** — временный токен на 24 часа (для первой проверки).
   - **From** — тестовый номер Meta. Под ним: **Phone number ID** и **WhatsApp Business Account ID**.
   - **To → Manage phone number list** → добавьте **свой личный номер WhatsApp** (придёт код подтверждения). Тестовый номер может писать только номерам из этого списка (до 5).
4. **App settings → Basic → App secret → Show** — скопируйте секрет приложения.
5. В Render → **Environment** заполните:
   - `WHATSAPP_TOKEN` — временный токен (позже заменим на постоянный, шаг 6);
   - `WHATSAPP_PHONE_NUMBER_ID` — Phone number ID;
   - `WHATSAPP_BUSINESS_ACCOUNT_ID` — WhatsApp Business Account ID;
   - `META_APP_SECRET` — App secret.
   Нажмите **Save Changes** — сервер перезапустится сам (1–2 минуты).
6. В Render → **Environment** нажмите на глаз 👁 у `WEBHOOK_VERIFY_TOKEN` и скопируйте значение.
7. Meta: **WhatsApp → Configuration** (Конфигурация) → **Webhook → Edit**:
   - **Callback URL**: `https://ВАШ-АДРЕС.onrender.com/webhook`
   - **Verify token**: значение `WEBHOOK_VERIFY_TOKEN`
   - **Verify and save**. Если ошибка — проверьте, что сервер Live и адрес без опечаток.
8. Там же **Webhook fields → Manage** → включите (**Subscribe**) поле **messages**.
9. В панели: **Настройки → Подключение WhatsApp** → все пункты с ✅, виден номер → нажмите **«Подписать приложение на сообщения»**.

## Шаг 5. Проверка реальной отправки и получения ✅

Это обязательная проверка, что всё работает по-настоящему.

**5.1. Отправка.** Панель → Настройки → Подключение WhatsApp → «Проверка отправки» → введите свой номер (например `77011234567`) → подтвердите.
На ваш WhatsApp придёт сообщение *Hello World* от тестового номера. ✔️ Отправка работает.

**5.2. Получение.** Ответьте на это сообщение со своего телефона, например «Привет».
В панели в **Диалогах** появится ваш диалог. ✔️ Получение работает.

**5.3. Ответ AI.**
1. Заполните **Инструкции** и **Знания** (хотя бы пару строк о бизнесе).
2. Во вкладке **Инструкции → «Проверить AI»** потренируйтесь: здесь ничего не отправляется клиентам.
3. Включите переключатель **AI** вверху панели.
4. Напишите со своего телефона на тестовый номер: «Сәлеметсіз бе, бағасы қанша?»
5. Через несколько секунд придёт ответ AI на казахском. ✔️ Система работает полностью.

Напишите мне, чем закончились 5.1–5.3. Если где-то ошибка, пришлите **текст ошибки из панели** (без ключей).

## Шаг 6. Постоянный токен (чтобы ничего не отключилось через 24 часа)

Временный токен живёт 24 часа. Постоянный создаётся так:
1. Откройте **https://business.facebook.com/settings** (настольная версия).
2. **Users → System users → Add** → имя `whatsapp-bot`, роль **Admin**.
3. **Assign assets**: **Apps** → ваше приложение → *Full control*; **WhatsApp accounts** → ваш аккаунт → *Full control*.
4. **Generate new token** → ваше приложение → срок **Never** → разрешения
   `whatsapp_business_messaging` и `whatsapp_business_management` → **Generate**.
5. Скопируйте токен → Render → Environment → замените `WHATSAPP_TOKEN` → **Save Changes**.

## Шаг 7. Работа 24/7 на бесплатном тарифе

Бесплатный сервер Render «засыпает» через 15 минут без запросов, и первый ответ после сна задерживается примерно на минуту (сообщения не теряются: Meta повторяет доставку).
Чтобы сервер не засыпал:
1. Откройте **https://cron-job.org** → бесплатная регистрация.
2. **Create cronjob** → URL: `https://ВАШ-АДРЕС.onrender.com/health` → каждые **10 минут** → Save.

Надёжнее всего платный тариф Render Starter ($7/мес). Переходить на него только по вашему решению.

## Шаг 8. Голосовые сообщения (необязательно)

1. **https://console.groq.com** → регистрация → **API Keys → Create API Key**.
2. Render → Environment → `STT_API_KEY` = этот ключ → Save.
Голосовые будут расшифровываться (Whisper понимает казахский и русский), и AI ответит по смыслу. Без ключа AI вежливо попросит написать текстом.

## Шаг 9. Push-уведомления, когда нужен владелец (необязательно)

1. App Store → приложение **ntfy** → «+» → придумайте длинное имя темы, например `wa-ai-7f3k9q2m` (это как пароль, не используйте простые слова).
2. Render → Environment → `NTFY_TOPIC` = то же имя → Save.
Вам будут приходить уведомления «Нужно ваше внимание: Айгерим — просит возврат». Текст переписки в уведомления не попадает.

## Ваш номер WhatsApp Business

Важно понимать варианты. **Ничего из этого не делайте без отдельного решения.**

1. **Совместная работа (Coexistence)** — номер остаётся в приложении WhatsApp Business на телефоне **и одновременно** подключается к API. Ваши ответы из приложения программа видит (поле `smb_message_echoes`) и сама ставит AI на паузу в этом диалоге.
   - Подключается только через **Embedded Signup** у официального партнёра Meta (Tech Provider / BSP). Обычно это платно; можно и самому стать Tech Provider, но для этого нужны верификация бизнеса и проверка приложения в Meta.
   - Нужна свежая версия приложения WhatsApp Business. Поддерживается не во всех странах; по последним данным Казахстана в списке исключений нет, но это проверяется при подключении.
   - При совместной работе недоступны некоторые функции приложения: исчезающие сообщения, просмотр один раз, трансляция геолокации, списки рассылки и др.
2. **Перенос номера полностью в API.** ❌ Приложение WhatsApp Business на этом номере перестанет работать. Вы это запретили, поэтому мы так не делаем.
3. **Отдельный номер для бота** (вторая SIM или eSIM). Самый простой и бесплатный путь: Meta → WhatsApp → API Setup → **Add phone number**.

Рекомендация: сначала полностью проверьте систему на **тестовом номере** (шаг 5), потом выберите вариант 1 или 3.

## Выход в рабочий режим (для писем клиентам с любых номеров)

Тестовый номер пишет только номерам из списка. Для настоящих клиентов:
1. Meta → **App settings → Basic** → **Privacy Policy URL**: `https://ВАШ-АДРЕС.onrender.com/privacy.html` (страница уже есть в программе).
2. Переключите приложение в режим **Live**.
3. Подключите настоящий номер (см. выше) и, при необходимости, пройдите **верификацию бизнеса** в business.facebook.com.

## Как пользоваться каждый день

- **AI вкл/выкл** — переключатель вверху. Выключили → клиентам никто не отвечает автоматически.
- **Вмешаться в диалог** — откройте диалог и напишите сами. AI в этом диалоге замолчит на 12 часов (настраивается). Кнопка **«Вернуть AI»** включает его обратно.
- **Отключить AI для конкретного человека** — в диалоге «Выключить AI для контакта».
- **Нужен владелец** — красная метка в списке. AI сам передаёт вам жалобы, возвраты и вопросы, на которые нет ответа в базе знаний.
- **Расходы** — Отчёты → Расходы API. При достижении месячного лимита AI останавливается и передаёт клиентов вам.
- **Правило WhatsApp 24 часа**: свободно писать клиенту можно в течение 24 часов после его последнего сообщения. Позже — только одобренным шаблоном. Программа это учитывает.

## Если что-то не работает

| Признак | Что проверить |
|---|---|
| Meta пишет ошибку при «Verify and save» | Сервер Live? `адрес/health` открывается? Verify token совпадает? |
| Сообщения не появляются в панели | Поле **messages** подписано (шаг 4.8)? Нажата «Подписать приложение» (шаг 4.9)? Ваш номер в списке получателей? |
| Появляются, но AI не отвечает | Переключатель AI включён? Есть баланс в Claude? Не исчерпан лимит? Нет паузы в диалоге? |
| «Error validating access token» | Истёк временный токен → сделайте шаг 6 |
| Ответ приходит с задержкой ~1 минута | Сервер засыпал → шаг 7 |
